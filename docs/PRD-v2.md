## 1. 产品概述

### 1.1 产品定位

**出逃指令**是一款面向城市年轻人的轻量级随机探索工具。核心价值主张：**通过随机化指令降低"周末去哪"的决策焦虑，让每一次出门变成一次有仪式感的小冒险。**

### 1.2 一句话描述

点击卡片或摇一摇手机，获得一条随机"出逃指令"，走出去，拍下来，变成一张城市记忆拍立得。

### 1.3 产品形态

微信小程序（WeChat Mini Program），无需下载，即用即走。

### 1.4 目标用户

| 用户画像 | 特征 | 核心痛点 |
|---------|------|---------|
| 城市白领 | 22-35岁，一二线城市，有周末但不知道去哪 | 选择太多，决策疲劳 |
| 独居青年 | 一个人住，周末容易宅 | 缺乏出门的动力和理由 |
| 轻度社交用户 | 偶尔约朋友但不想去大众景点 | 厌倦了大众点评/小红书的同质化攻略 |
| 文艺爱好者 | 喜欢拍照、手账、小众体验 | 需要"有趣但不刻意"的体验灵感 |

### 1.5 北极星指标

**周活跃用户完成出逃指令的比率**（接受指令 → 执行 → 完成记录）。不是打开率，不是点击率，是"真正出门了"。

## 2. 市场与用户

### 2.1 竞品分析

| 产品 | 核心机制 | 差异化 | 弱点 |
|------|---------|--------|------|
| 大众点评 | 搜索+评价 | 数据量大 | 决策成本高，千人一面 |
| 小红书 | UGC攻略 | 内容丰富 | 滤镜化严重，真实感差 |
| 随机旅行App | 纯随机 | 新奇感 | 缺乏仪式感和记录闭环 |
| **出逃指令** | 随机+仪式感+记录 | 轻量化、拍立得记忆、手绘风 | 内容池和个性化不足（当前阶段） |

### 2.2 用户旅程

```
打开小程序 → 看到问候（天气+位置+时间适配）
    → 选择模式（智能匹配 / 微出逃 / 城市漫游）
    → 点击或摇一摇
    → 获得一条指令（类型 + 标题 + 场景插画 + 时长/距离/人数 + 小贴士）
    → 接受指令 → 开始执行
    → 执行中（4步引导 + 计时器 + 拍照）
    → 完成出逃 → 记录（拍立得卡片 + 滤镜 + 心情 + 感受）
    → 保存 → 分享卡片 / 钉到地图
    → 回到首页，解锁徽章
```

## 3. 核心问题诊断

### 3.1 信息分发效率为零（张一鸣视角）

**问题：** `app.js` 中 `fetchWeather()` 和 `scanNearbyPOI()` 全部返回硬编码值。`rollCommand()` 的匹配逻辑是纯客户端过滤，没有基于用户历史的个性化推荐。`completedCommandIds` 只用于避免重复，未用于理解用户偏好。

**根因：** 产品没有信息输入端，指令匹配等同于随机数生成。

**解决方案：**
- 接入真实天气 API（和风天气免费版）
- 接入真实定位（已有 `wx.getLocation`，仅需使用结果）
- 新增偏好学习：记录用户完成后的心情贴纸，下次摇指令时给偏好类型 +20% 权重

### 3.2 白痴指数过高的功能（马斯克视角）

| 功能 | 白痴指数 | 判定 |
|------|---------|------|
| 会员系统（无真实支付） | 10/10 | 砍掉 |
| 双人模式（无社交基础设施） | 9/10 | 隐藏 |
| 创建指令（空页面） | 9/10 | 砍掉 |
| 6种模式（数据无法支撑差异化） | 8/10 | 简化为3种 |
| 地图页（仅标记点查看器） | 7/10 | 重做为记忆地图 |

**解决方案：** 实施五步算法——质疑需求 → 删除不必要 → 简化 → 加速 → 自动化。

### 3.3 设计品质问题（乔布斯视角）

| 问题 | 位置 | 严重程度 |
|------|------|---------|
| "放弃"按钮调用空函数 `stopProp(){}` | 首页指令详情卡 | 高 |
| `buildSteps()` 生成了4步但WXML未使用 | 执行页 | 高 |
| 卡片图标用飞机（send）而非骰子 | 首页 | 中 |
| 问候语+天气+位置占3行信息层级 | 首页 | 中 |
| 徽章用Unicode字符✦❼☾ | 徽章页 | 中 |
| 记录保存后跳地图而非展示分享卡片 | 记录页 | 高 |

## 4. 功能需求

### 4.1 首页（出逃）

#### FR-1.1 问候与状态栏
- **现状：** 问候语 + 天气栏 + 位置栏，3行
- **目标：** 合并为1行：`"早啊，广州·天河 26℃ 晴"`
- **数据来源：** 真实天气API + 真实定位

#### FR-1.2 模式选择
- **现状：** 6个模式芯片（智能匹配/微出逃/城市漫游/雨天/深夜/双人）
- **目标：** 简化为3个：智能匹配（默认）、微出逃（<15分钟）、城市漫游（户外）
- **交互：** 点击震动 + 高亮 + Toast提示
- **雨天/深夜逻辑：** 融入智能匹配的自动过滤，不再作为独立模式

#### FR-1.3 出逃触发交互
- **现状：** 飞机图标 + 同心圆动画 + 600ms延迟，标题"摇一摇"暗示只能摇动
- **目标：** 骰子图标（替换飞机）+ 呼吸缩放动画 + 点击脉冲环提示 + 200ms延迟；标题改为"出逃一下"，副标题明确"点击卡片 或 摇一摇手机"
- **触发方式：** 点击卡片（bindtap）+ 加速度传感器（阈值>3.0，间隔>300ms），两种方式等效

#### FR-1.4 指令详情卡
- **触发：** 摇出指令后从下往上滑入
- **内容：** 类型标签 + 标题 + 场景插画 + 元信息（时长/距离/人数）+ 小贴士
- **操作：** 重摇（消耗换卡次数）+ 接受指令（跳转执行页）+ 关闭（关闭卡片）
- **修复：** "放弃"按钮改为"关闭"，不再调用空函数

#### FR-1.5 收藏按钮
- **位置：** 出逃卡片底部
- **行为：** 跳转到收藏列表页

### 4.2 执行页

#### FR-2.1 步骤引导
- **新增：** 4步可视化步骤指示器
- **状态：** 已完成（打勾+绿色）/ 当前步骤（高亮+脉冲动画）/ 待完成（灰色）
- **步骤内容：** 从指令的 `steps` 字段读取，兜底为通用步骤

#### FR-2.2 计时器
- **显示：** "已探索 XX 分钟"（友好文案，非纯数字）
- **进度条：** 基于指令时长计算百分比

#### FR-2.3 拍照
- **限制：** 最多3张
- **来源：** 相机 + 相册
- **存储：** 临时文件路径，完成时持久化

#### FR-2.4 完成按钮
- **样式：** 大尺寸、全宽、品牌色、圆角
- **反馈：** 长震动 + 跳转记录页

### 4.3 记录页

#### FR-3.1 拍立得卡片
- **布局：** 照片 + 心情贴纸（右上角覆盖）+ 感受文字 + 日期/时间/天气
- **旋转：** 随机 -2° 到 +2° 倾斜
- **滤镜：** 日光/阴雨天/闪光灯，3选1

#### FR-3.2 心情贴纸
- **选项：** 开心/平静/惊喜/治愈/好玩，5选1
- **交互：** 点击选中，选中态加绿色边框
- **数据用途：** 存储为用户偏好，用于下次指令推荐

#### FR-3.3 一句话感受
- **输入方式：** 点击弹窗编辑（保留现有），未来改为内联输入
- **字数限制：** 200字

#### FR-3.4 保存与分享
- **保存流程：** 记录→过渡动画页→完成保存→展示成功弹层
- **新增分享卡片：** 使用Canvas生成一张包含照片+指令+日期+天气+心情的合成图
- **分享入口：** 保存成功弹层中的"分享给朋友"按钮（微信原生分享）+ "保存到相册"按钮

### 4.4 地图页（记忆地图）

#### FR-4.1 地图展示
- **底层：** 微信原生 `<map>` 组件
- **标记点：** 6种类型使用6种不同颜色/图标的手绘风格标记
- **默认视图：** 以用户当前位置为中心，缩放级别15

#### FR-4.2 悬浮控件
- **定位：** 移动到用户当前位置
- **刷新：** 重新加载记录数据

#### FR-4.3 底部数据卡
- **内容：** 出逃次数 / 探索角落 / 徽章数 / 连续天数
- **样式：** 白色卡片，圆角，手绘风格边框

#### FR-4.4 标记交互
- **点击标记：** 弹出该次出逃的简要信息卡片
- **信息内容：** 指令标题 + 日期 + 心情

### 4.5 我的页面

#### FR-5.1 用户信息
- **头像：** 默认头像或用户自定义
- **名称：** 随机生成的"出逃代号"（如"摘云的漫步者"），可修改
- **出逃代号：** 可编辑，限制12字

#### FR-5.2 数据统计
- **4项指标：** 出逃次数 / 步行公里 / 连续天数 / 探索角落
- **数据来源：** `globalData.records` 实时计算

#### FR-5.3 徽章墙
- **展示：** 最近4个徽章，点击进入完整徽章页
- **状态：** 已获得（彩色） / 未获得（灰色+锁）

#### FR-5.4 功能入口
- 会员入口（暂时隐藏）
- 我的收藏
- 设置

### 4.6 徽章页

#### FR-6.1 徽章展示
- **布局：** 3列网格
- **每个徽章：** 圆形图标 + 徽章名称 + 获得日期（或"未解锁"）
- **已解锁：** 渐变背景 + 光泽效果 + 阴影
- **未解锁：** 灰色 + 半透明

#### FR-6.2 徽章交互
- **点击已解锁：** 弹窗显示徽章名称和描述
- **点击未解锁：** Toast提示"继续出逃解锁这枚徽章"

#### FR-6.3 进度条
- **顶部：** "已收集 X / 9" + 进度条

### 4.7 收藏页

#### FR-7.1 收藏列表
- **布局：** 卡片式列表，每张卡片左侧信息右侧配图
- **操作：** 点击查看详情 / 右侧X按钮移除 / 长按快速移除

#### FR-7.2 空状态
- **展示：** 心形图标 + "还没有收藏任何指令" + 引导按钮

### 4.8 设置页

#### FR-8.1 偏好设置
- 音效开关
- 震动反馈开关
- 每日提醒开关

#### FR-8.2 定位模式
- 模糊定位（默认）
- 精确定位

#### FR-8.3 其他
- 关于
- 清空所有数据（二次确认）

## 5. 非功能需求

### 5.1 性能
- 首页加载 < 1.5秒
- 触发响应 < 200ms
- 拍照保存 < 2秒
- 页面转场 < 300ms

### 5.2 兼容性
- 微信最低版本：7.0.0
- iOS 12+ / Android 8.0+
- 屏幕适配：375px - 428px 宽度

### 5.3 数据安全
- 所有数据存储在本地 `wx.Storage`
- 不收集用户隐私数据（不要求手机号/微信登录）
- 位置数据仅用于本地匹配，不上传服务器

### 5.4 可用性
- 所有可点击区域 ≥ 44×44px（微信规范）
- 震动反馈可关闭
- 图片加载失败有占位状态
- Toast提示 ≤ 2行

## 7. 数据模型

### 7.1 指令（Command）

```typescript
interface Command {
  id: string;           // 唯一标识，如 'c001'
  title: string;        // 指令标题，如 '寻找街角的蓝色'
  content: string;      // 指令详细内容
  type: 'color' | 'walk' | 'sense' | 'collect' | 'food' | 'culture';
  typeColor: string;    // 类型颜色，如 '#5B8FB9'
  duration: number;     // 预计时长（分钟）
  outdoor: boolean;     // 是否户外
  nightSafe: boolean;   // 夜间是否安全
  rainy: boolean;       // 雨天是否适合
  requirePOI: string | null; // 需要的POI类型
  tip: string;          // 小贴士
  difficulty: 1 | 2 | 3;     // 难度 1-3
  energy: 'low' | 'medium' | 'high'; // 精力消耗
  social: boolean;      // 是否社交类
  steps: string[];      // 分步引导，如 ['走出家门', '找到蓝色的东西', ...]
}
```

### 7.2 记录（Record）

```typescript
interface Record {
  id: string;           // 自动生成 'r_' + timestamp
  commandId: string;    // 关联指令ID
  commandContent: string;
  commandType: string;
  typeColor: string;
  duration: number;     // 实际执行时长（分钟）
  photos: string[];     // 照片临时路径
  feeling: string;      // 一句话感受
  mood: 'happy' | 'calm' | 'surprise' | 'heal' | 'fun';
  location: { latitude: number; longitude: number } | null;
  weather: object | null;
  date: string;         // 'YYYY-MM-DD'
  time: string;         // 'HH:MM'
  filter: 'day' | 'rain' | 'flash';
}
```

### 7.3 徽章（Badge）

```typescript
interface Badge {
  id: string;           // 如 'first_escape'
  name: string;         // 如 '初次出逃'
  desc: string;         // 徽章描述
  icon: string;         // 图标路径
  gradient: string;     // 背景渐变CSS
  color: string;        // 图标颜色
  unlocked: boolean;    // 是否已解锁
  date?: string;        // 解锁日期
}
```

### 7.4 全局状态（GlobalData）

```typescript
interface GlobalData {
  userInfo: null;
  systemInfo: object;
  currentCommand: Command | null;
  commandStatus: 'idle' | 'executing' | 'cooldown';
  location: { latitude: number; longitude: number } | null;
  locationName: string;
  locationMode: 'fuzzy' | 'precise';
  weather: { condition: string; temperature: number; description: string } | null;
  reRollCount: number;  // 每日换卡次数，默认3
  records: Record[];
  completedCommandIds: string[];
  badges: Badge[];
  pendingBadges: string[];
  collectedCommands: string[];
  commandPool: Command[];
  offlineCommands: Command[];
  onboarded: boolean;
  continuousDays: number;
  lastCompleteDate: string;
  userPreferences: { mood: Record<string, number> }; // 新增：用户偏好权重
}
```
