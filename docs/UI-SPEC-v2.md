## 1. 设计理念

### 1.1 三个关键词

- **手绘感（Sketch-like）：** 线条不是完美的直线，图标不是几何拼凑，整体有"人画出来"的温度
- **杂志排版（Editorial）：** 像一本独立杂志，有呼吸感、留白大胆、图文比例舒适
- **反AI化（Anti-synthetic）：** 拒绝AI生成的千篇一律的美学——没有渐变色块堆砌、没有霓虹发光、没有多余的装饰

### 1.2 设计原则

1. **一个呼吸的节奏：** 用户打开小程序到看到第一条指令，3秒内完成理解
2. **每次交互有反馈：** 震动 + 动画 + 状态变化，缺一不可
3. **空状态不是空白：** 每个列表/网格在无数据时展示引导性空状态
4. **少即是多：** 一个页面最多3个视觉层级，超过就拆分
5. **真实优先：** 用真实照片和手绘插图，不用AI生成的"完美"图片

### 1.3 视觉参考

- **杂志：** Cereal Magazine, Kinfolk, Apartamento
- **App：** 潮汐 (Tide), 小宇宙, Day One, 黄油相机
- **风格：** 图5（用户提供的参考图）

## 3. 字体系统

### 3.1 字体族

```css
font-family: -apple-system, BlinkMacSystemFont, "PingFang SC",
  "Helvetica Neue", "Microsoft YaHei", sans-serif;

/* 等宽数字字体 */
.font-mono {
  font-family: "SF Mono", "Menlo", "Consolas", monospace;
}
```

### 3.2 字号层级

| 层级 | 字号 | 字重 | 用途 | 行高 |
|------|------|------|------|------|
| H1 | 44rpx | 700 | 页面大标题 | 1.2 |
| H2 | 36rpx | 700 | 页面标题 | 1.3 |
| H3 | 30rpx | 600 | 卡片标题 | 1.4 |
| Body | 28rpx | 400 | 正文 | 1.5 |
| Caption | 24rpx | 400 | 辅助文字 | 1.4 |
| Small | 22rpx | 400 | 标签、小字 | 1.4 |
| Tiny | 20rpx | 400 | 极小文字 | 1.3 |
| Number | 44rpx | 700 | 数值展示 | 1.1 |

### 3.3 使用规则

- 正文永远使用 28rpx，不要用 26rpx 或 30rpx
- 数字展示使用等宽字体，确保对齐
- 标题不超过2行，正文不超过4行
- 英文和数字与中文之间加空格（如 "26℃ 晴"）

### 4.2 元素间距

| 关系 | 间距 |
|------|------|
| 标题与副标题 | 8rpx |
| 标题与正文 | 16rpx |

| 列表项间距 | 0（用分割线） |

### 4.3 触控区域

```
最小可点击区域：88rpx × 88rpx（微信规范的44px × 44px）
按钮高度：80rpx（主要按钮）/ 64rpx（次要按钮）
图标按钮：72rpx × 72rpx（圆形）
```

### 4.4 安全区域

```
状态栏高度：动态（wx.getSystemInfoSync().statusBarHeight）

TabBar高度：160rpx + env(safe-area-inset-bottom)
底部安全区：env(safe-area-inset-bottom)
```

## 5. 圆角体系

| 名称 | 值 | 用途 |
|------|------|------|
| `--radius-sm` | 12rpx | 标签、芯片、输入框 |
| `--radius-md` | 20rpx | 卡片内部元素、图片 |
| `--radius-lg` | 28rpx | 普通卡片 |
| `--radius-xl` | 36rpx | 大卡片、弹层 |
| `--radius-pill` | 100rpx | 按钮、TabBar、胶囊 |

**规则：** 同一层级的元素使用统一的圆角值。不要把不同圆角混用在同一视觉层级。

## 6. 阴影层级

| 名称 | 值 | 用途 |
|------|------|------|
| `--shadow-card` | `0 2rpx 16rpx rgba(46,47,51,0.04)` | 普通卡片 |
| `--shadow-elevated` | `0 4rpx 24rpx rgba(46,47,51,0.08)` | 浮层卡片 |
| `--shadow-popup` | `0 8rpx 40rpx rgba(46,47,51,0.12)` | 弹层、Modal |
| `--shadow-float` | `0 2rpx 12rpx rgba(46,47,51,0.06)` | 悬浮按钮 |

**规则：** 阴影值全部使用 `rgba(46,47,51,...)` 带暖色底色，不使用纯黑阴影。阴影只用于表达Z轴层级，不用于装饰。

## 8. 动效规范

### 8.1 缓动函数

```css
/* 标准缓动（大部分交互） */
--ease-standard: cubic-bezier(0.25, 0.1, 0.25, 1.0);

/* 弹性缓动（弹窗、卡片出现） */
--ease-bounce: cubic-bezier(0.34, 1.56, 0.64, 1.0);

/* 减速缓动（消失、关闭） */
--ease-out: cubic-bezier(0.0, 0.0, 0.2, 1.0);
```

### 8.2 时长

| 场景 | 时长 | 缓动 |
|------|------|------|
| 页面转场 | 250ms | standard |
| 卡片出现 | 300ms | bounce |
| 按钮按下 | 150ms | standard |
| 出逃触发动效 | 400ms | bounce |
| 点击脉冲环 | 2500ms | ease-in-out（循环） |
| 徽章弹出 | 800ms | bounce |
| Toast | 2000ms | — |

### 8.3 具体动效

#### 出逃触发动效（点击/摇动通用）

触发后骰子图标执行以下动画序列：
```
1. 骰子图标缩小到 0.85 → 0ms
2. 弹回 1.05 → 100ms
3. 回弹到 1.0 → 200ms
4. 同时呼吸缩放（1.0 ↔ 1.04）循环2次 → 400ms
```

#### 点击脉冲环（空闲态提示）

骰子外围持续播放脉冲环，暗示卡片可点击：
```
1. 从 scale(0.96) opacity(0) 开始
2. 到 scale(1.04) opacity(0.5) → 1250ms
3. 回到 scale(0.96) opacity(0) → 1250ms
4. 循环播放，2.5s一个周期
```

#### 指令卡片出现

```
从下往上滑入（translateY: 40rpx → 0）
同时淡入（opacity: 0 → 1）
时长 300ms，bounce 缓动
```

#### 徽章解锁

```
1. 徽章从 0 缩放到 1.3 → 300ms
2. 回弹到 1.0 → 200ms
3. 光泽从左到右扫过 → 500ms
总时长 800ms
```

#### 拍立得保存

```
卡片从中间放大（scale: 0.9 → 1.0）
同时淡入（opacity: 0 → 1）
时长 500ms，bounce 缓动
```

## 10. 图标与插图

### 10.1 图标风格

- **风格：** 手绘线条风（Line Art），非几何填充风
- **线条粗细：** 1.5px - 2px（统一）
- **角落处理：** 圆角端点（round cap），圆角连接（round join）
- **颜色：** 单色，使用CSS变量控制（`currentColor`），不内嵌颜色
- **格式：** SVG
- **尺寸：** 48×48px 画布，内容区 32×32px

### 10.2 插图风格

- **风格：** 手绘水彩风（Watercolor），非扁平矢量风
- **色调：** 暖色系，低饱和度，与品牌色协调
- **内容：** 具体场景（咖啡店、街角、书店），非抽象图案
- **格式：** WebP（有损压缩，质量85%）
- **尺寸：** 750×400px（3:2横版场景）/ 750×1334px（竖版全屏）

## 11. 文案规范

### 11.1 品牌语调

- **温暖但不矫情：** 不说"治愈你的心灵"，说"出去走走心情会好"
- **具体但不啰嗦：** 不说"在附近的区域进行一段短途的探索"，说"下楼走15分钟"
- **有趣但不轻浮：** 不说"冲鸭！"，说"出发吧"
- **真诚但不严肃：** 不说"根据算法推荐"，说"帮你挑了一条"

### 11.2 指令文案格式

每条指令遵循"动作 + 对象 + 目标"结构：

**好的指令：**
- "找到3样蓝色的东西，拍下来"
- "去最近的小店买一个你很久没吃过的零食"
- "沿着一条没走过的路走15分钟"
- "在街角的面包店买一个刚出炉的牛角包"
- "找一个可以坐下来的地方，看10分钟云"

**不好的指令：**
- "探索城市中的蓝色元素"（太抽象）
- "进行一次怀旧零食购买体验"（太正式）
- "开启一段城市漫步之旅"（太空洞）

### 11.3 问候语文案

```
05:00-08:59  → "早啊，早起的人有风景看"
09:00-11:59  → "上午好，今天天气不错，出去走走？"
12:00-13:59  → "午安，午饭后散散步吧"
14:00-16:59  → "下午好，给下午一个小冒险"
17:00-18:59  → "傍晚好，日落前出去走走"
19:00-21:59  → "晚上好，周五了，想好周末去哪了吗？"
22:00-04:59  → "夜深了，睡不着就起来透透气"
```

### 11.4 按钮文案

```
接受指令     → "接受指令"（不用"开始"、"GO"）
出逃一下     → "出逃一下"（不用"摇一摇"、"Shake"、"随机出逃"）
完成出逃     → "完成出逃"（不用"Finish"、"结束"）
保存记录     → "保存记录"（不用"Save"、"提交"）
重摇         → "重摇"（不用"换一个"、"再来一次"）
关闭         → "关闭"（不用"放弃"、"取消"）
```

## 12. 反AI化设计原则

### 12.1 什么是"反AI化"？

AI生成的设计有几个共同特征，我们要刻意避免：

| AI特征 | 我们的做法 |
|--------|-----------|
| 渐变色块堆砌 | 只用纯色+阴影，渐变仅用于徽章背景 |
| 霓虹发光效果 | 无发光，阴影是柔和的暖灰色 |
| 几何完美对称 | 手绘感线条，允许轻微不对称 |
| 无意义的装饰元素 | 每个元素都有功能，删除纯装饰 |
| 千篇一律的圆角卡片 | 不同层级不同圆角，有节奏感 |
| Emoji作为图标 | 全部使用手绘SVG图标 |
| 过度饱和的色彩 | 低饱和度、暖色调、克制 |
| AI生成的不真实配图 | 用真实照片或手绘水彩插图 |

### 12.2 具体执行

1. **图标：** 全部使用手绘线条SVG，不用Emoji，不用Material Design图标
2. **插图：** 全部使用真实照片（由用户拍摄）或手绘水彩风插图，不用AI生成图片
3. **色彩：** 饱和度控制在40-60%，不过度鲜艳
4. **排版：** 像杂志一样留有呼吸感，不塞满每一个像素
5. **动效：** 有弹性但不夸张，不滥用动画
6. **文案：** 像人在说话，不像AI在写广告
