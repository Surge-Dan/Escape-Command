# 出逃指令 v2.0 — 体验设计规范

> 一个真正好用的产品，不是在功能上做加法，而是在体验上做减法。
> 本文档定义 v2.0 的交互规范、视觉语言和UX原则。

---

## 一、核心体验原则

### 1.1 一个呼吸的节奏

用户打开小程序到看到第一条指令，理想时间是 **3秒以内**。在这个时间里：
- 第1秒：看到问候 + 天气 + 位置（一行）
- 第2秒：看到模式选择（默认智能匹配）
- 第3秒：点击/摇一摇，看到指令

**任何超过3秒才能理解的信息，都需要重新设计。**

### 1.2 每次交互都有反馈

| 交互 | 反馈 |
|------|------|
| 点击模式芯片 | 震动 + 芯片高亮 + Toast提示模式名称 |
| 摇一摇 | 震动 + 骰子动画 + 600ms后展示指令 |
| 接受指令 | 长震动 + 页面转场 |
| 完成出逃 | 长震动 + 拍立得卡片出场动画 |
| 保存记录 | 震动 + 成功弹层 + 分享入口 |
| 解锁徽章 | 徽章弹出动画 + 震动 |

### 1.3 空状态不是空白

每个列表/网格在无数据时，展示引导性空状态，而非空白：
- 收藏页：`♡ 还没有收藏任何指令` + `去创建专属指令` 按钮
- 地图页：`还没有出逃记录` + `去摇一摇` 按钮
- 记录页：默认占位图 `latte.webp`

## 二、视觉语言升级

### 2.1 色彩系统

```
主色调：薄荷绿 #5CBF9E（品牌色）
背景色：暖白 #F5F3EF（canvas）
文字色：墨黑 #2E2F33（ink）
辅助色：柔和灰 #6B7280（ink-soft）
淡灰 #A8ADB5（ink-faint）
强调色：暖橙 #D48A5A（accent）
危险色：柔红 #E05555（danger）
```

### 2.2 圆角体系

```
小圆角：12rpx（标签、芯片）
中圆角：20rpx（卡片内部元素）
大圆角：28rpx（卡片）
超大圆角：36rpx（大卡片）
胶囊：100rpx（按钮、TabBar）
```

### 2.3 阴影层级

```
卡片阴影：0 2rpx 16rpx rgba(46,47,51,0.04)
浮层阴影：0 4rpx 24rpx rgba(46,47,51,0.08)
弹层阴影：0 8rpx 40rpx rgba(46,47,51,0.12)
```

### 2.4 字体层级

```
大标题：36rpx / 700 / 品牌色或墨黑
标题：30rpx / 600 / 墨黑
正文：28rpx / 400 / 墨黑
辅助文字：24rpx / 400 / 柔和灰
小字：22rpx / 400 / 淡灰
数字：等宽字体 Inter/DIN（数值展示）
```

## 四、动效规范

| 场景 | 动效 | 时长 |
|------|------|------|
| 摇一摇 | 骰子弹跳 + 呼吸缩放 | 600ms |
| 指令卡片出现 | 从下往上滑入 + 淡入 | 300ms |
| 模式切换 | 芯片缩放 + 颜色渐变 | 200ms |
| 徽章解锁 | 弹出 + 旋转 + 光效 | 800ms |
| 记录保存成功 | 拍立得卡片从中间放大 | 500ms |
| 页面转场 | 右滑进入/左滑退出 | 250ms |

## 五、文案规范

### 5.1 品牌语调

- **温暖但不矫情**：不说"治愈你的心灵"，说"出去走走心情会好"
- **具体但不啰嗦**：不说"在附近的区域进行一段短途的探索"，说"下楼走15分钟"
- **有趣但不轻浮**：不说"冲鸭！"，说"出发吧"

### 5.2 指令文案

每条指令遵循"动作 + 对象 + 目标"结构：
- ✅ "找到3样蓝色的东西，拍下来"
- ✅ "去最近的小店买一个你很久没吃过的零食"
- ✅ "沿着一条没走过的路走15分钟"
- ❌ "探索城市中的蓝色元素"
- ❌ "进行一次怀旧零食购买体验"

## 六、可访问性检查

- [ ] 文字对比度 ≥ 4.5:1（正文/背景）
- [ ] 可点击区域 ≥ 44×44px（微信规范）
- [ ] 震动反馈可关闭（设置页）
- [ ] 图片有占位状态（加载中/加载失败）
- [ ] Toast提示不超过2行
