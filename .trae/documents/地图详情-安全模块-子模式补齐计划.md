# 地图详情 + 安全模块 + 微逃子模式补齐 实施计划

## Context（背景与目标）

用户反馈三类问题，需基于《出逃指令-产品总纲与完整功能规划》补齐：

1. **地图页点位点击无详情**：当前 marker 弹窗仅显示 类型/标题/日期（`map.js:formatPopup` 365-376），缺失出逃模式/搭子/时长/心情/天气/照片，且无"查看详情"入口。产品文档 12.8 行 892 定义「点位详情（查看照片、文字、天气）」为 P0。
2. **安全模块缺失**：executing 页仅有 goBack（abandon），无显式 紧急退出/分享位置/安全提示。产品文档 15 章 + 12.5 行 825-826 定义 紧急退出 P0、安全提示 P0、分享位置 P1。
3. **微逃子模式被移除**：MODE_LIST 含 7 个模式（smart/micro/walk/double/night/rainy/breakthrough），但首页无模式选择 Tag→Sheet（项目记忆约束：「首页顶部模式选择需通过点击Tag弹出Sheet实现」），selectedMode 恒为 'smart'，子模式（雨天/双人/城市漫游/深夜）无法触发。

审计确认：onboarding（保持现状）、profile/settings/badges/collection/member/daily-challenge 均已实现，数据联动（records→map/profile/badges）主干正常。本计划聚焦上述三类缺口 + 数据联动验证 + 全量测试。

**复用资产**：`pages/record-detail/record-detail.js`（已完整实现，按 `?id=` 加载记录，展示照片/心情/类型/模式/天气/位置/同频摘要，含收藏/删除/分享）——地图弹窗"查看完整记录"直接复用此页，无需新建。

## Part A：地图页点位详情（用户 #1，最高优先）

### A1. 富化 marker 弹窗
**文件**：`pages/map/map.js`（`formatPopup` 365-376）、`pages/map/map.wxml`（popup 112-118）、`pages/map/map.wxss`

- `formatPopup(record)` 扩充字段：`modeName`（出逃模式，从 record.commandType + MODE_LIST 推导）、`partnersText`（搭子：同频取 record.members 名字；破圈取"独自突破"；普通取 cmd.people 或"独行"）、`durationText`（时长，record.duration 分钟）、`moodName`（心情，MOODS.find）、`weatherText`、`photoThumb`（record.photos[0]）、`isBreakthrough`
- 弹窗 UI 改为富卡片：顶部照片缩略图（cover-image）+ 类型色条 + 标题 + 元信息网格（模式/搭子/时长/心情/天气）+ 底部"查看完整记录 ›"按钮
- 弹窗容器改 `catchtap` 阻止冒泡关闭，仅"查看完整记录"按钮 `bindtap="goRecordDetailFromMap"` 触发跳转；保留外部遮罩点击关闭

### A2. 跳转 record-detail
**文件**：`pages/map/map.js` 新增 `goRecordDetailFromMap(e)`
- 从 `popupRecord.id` 取 recordId，`wx.navigateTo('/pages/record-detail/record-detail?id=' + id)`
- 复用现有 record-detail 页（已验证参数匹配：home 页 goRecordDetail 也用 `?id=`）

### A3. 修复地图已知 Bug
- **B4 灰色地带**：`totalCount` 改用 `located.length`（有坐标记录数）作空状态判断；无坐标记录单独提示"N 条未留痕"小字
- **B1 route 无 homePoint**：`onTabTap` 中 route 无 homePoint 时 toast 后 `return`，不切换
- **B5 homePoint fallback**：`setHomePointFallback` 优先用 `app.globalData.location`，其次 mapCenter
- **B3 callout**：`bindcallouttap="onMarkerTap"` 补绑（map.wxml:35）

### A4. 增加类型 + 心情筛选
**文件**：`pages/map/map.js`、`map.wxml`、`map.wxss`
- 新增 `TYPE_FILTERS`（全部/微逃/破圈/同频，按 record.commandType 映射）+ `MOOD_FILTERS`（全部 + MOODS 5 项）
- `filterRecords` 增加 type/mood 过滤维度，与现有 time 过滤组合
- UI：time-chips 下方加 type-chips + mood-chips 横滑条（cover-view，与现有 time-chips 风格一致）

## Part B：安全模块（executing 页，P0+P1）

**文件**：`pages/executing/executing.js`、`executing.wxml`、`executing.wxss`

### B1. 安全提示卡（P0）
- 新增 `safetyTip` 计算（onLoad）：根据 `app.getCurrentHour()`（夜间 21-6 提示"夜间出逃注意安全"）+ `weather.condition`（rainy 提示"雨天路滑，优先室内"）+ 破圈模式（提示"已离开舒适区，随时可退出"）生成 `safetyTipText`
- 卡片插在步骤卡上方（与小贴士区分：安全卡用警示色边框 #E07A5F，小贴士保持品牌色）
- 无安全风险时不显示（避免噪音）

### B2. 紧急退出（P0）
- 顶部 nav-header 右侧加"紧急退出"文字按钮（替代/补充现有 goBack），显式调用 `app.abandonCommand()` + `wx.switchTab('/pages/index/index')`
- 现有 goBack（左箭头）保留为"返回"，语义区分：左箭头=返回上页，紧急退出=一键结束任务回首页
- 加 `wx.showModal` 二次确认"确定结束本次出逃？记录会丢失"

### B3. 分享位置（P1）
- 安全卡内加"分享位置给好友"按钮，调用 `wx.openLocation`（传 currentCommand.location 或 globalData.location 的 lat/lng + name）
- 低版本不支持时降级为 `onShareAppMessage` 带位置

## Part C：微逃子模式补齐（首页 Tag→Sheet）

**文件**：`pages/index/index.js`、`index.wxml`、`index.wxss`、`utils/constants.js`

### C1. 首页模式 Tag
- hero 区（hero-warm 内，dateText pill 旁）加可点击 Tag 显示当前模式名（如"智能匹配"）+ 下拉箭头
- 点击触发 `onModeTagTap` → `setData({ showModeSheet: true })`

### C2. 模式选择 Sheet
- 复用现有 dice-sheet 结构，新建 mode-sheet：展示 6 个子模式（智能匹配/城市漫游/双人出逃/深夜出逃/雨天出逃/破圈——breakthrough 已有独立骰子，可在 sheet 内提示"破圈请切到破圈骰子"或隐藏）
- 每项显示 icon + name + desc，选中态高亮
- SHEET_MODES 扩展为含全部子模式（或在 index.js 内联定义 MODE_SHEET_LIST，不改 constants.js SHEET_MODES 避免影响其他引用）

### C3. 模式生效逻辑
- 选中模式后：更新 `selectedMode` + `heroSubText`（按模式 desc）+ `heroColor`（模式 color）+ 持久化 `wx.setStorageSync('lastMode', id)`
- `loadDailyRecommend` 增加模式过滤：double→cmd.double/social；rainy→cmd.rainy；walk→type=walk/duration>=30；night→cmd.nightSafe
- onShow 恢复 lastMode

### C4. 差异化保持
- 微逃骰子（Cover Flow #1）仍走 7D 表单（dice-micro-7d），不受 mode 影响——7D 已有完整维度选择
- 模式 Tag 仅影响"今日推荐"筛选 + hero 视觉，不与骰子 Cover Flow 冲突
- 三个骰子模式（微逃7D/破圈勇气/同频组局）保持各自独立流程
