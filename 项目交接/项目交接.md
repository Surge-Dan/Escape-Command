## 一、最终目标

将微信小程序「出逃指令」首页UI改造为参考图/演示视频中的骰子Cover Flow风格，具体包括：
- 冰蓝纯色背景 `#E8F4FC`
- 居中衬线体标题「出逃指令」
- 顶部日期胶囊（M月D日 · 周X）
- 动态时段问候语
- **3颗金属质感骰子（红/紫/绿）Cover Flow布局**：中间红（微逃）放大、两侧缩小带透视，支持左右滑动换位、3秒自动循环切换、待机呼吸浮动
- 点击「投掷」后骰子翻滚旋转，跳转到对应模式页面
- 蓝色渐变模式名称胶囊、「点击投掷」呼吸提示、蓝色圆点指示器
- 收藏入口/上次记录/最近出逃 内容区下移（下滑可见）
- 底部悬浮胶囊式**纯文字TabBar**（出逃/地图/我的），选中项蓝色渐变白字
- **保留音效以外的所有视觉效果**

## 八、重要决策及其理由

| 决策 | 理由 |
|---|---|
| 使用预渲染帧图方案（CSS变换+静态图片）而非3D库 | 用户之前因觉得丑回滚过3D元素；避免引入Three.js等重型库影响小程序性能；CSS方案实现快、兼容性好 |
| 骰子两侧使用 scale(0.65) + rotateY(±25deg) | 模拟Cover Flow透视效果，中间突出两侧后退，符合演示视频中的视觉层次 |
| 自动切换3秒间隔 | 用户明确确认 |
| 投掷动画900ms时长+100ms骰面切换频率 | 平衡动画流畅度和响应速度，太快看不清翻滚，太慢用户等得急 |
| 骰子初始顺序 [micro, sync, breakthrough] | 对应「中红、右绿、左紫」的位置，符合用户指定的「左紫=破圈、中红=微逃、右绿=同频」 |
| 破圈投掷后直接摇指令弹窗而非跳新页面 | 用户说「破圈→破圈界面」，现有逻辑就是在首页摇完弹出结果卡，没有独立破圈页面（只有 breakthrough-profile 是个人主页相关），所以沿用现有弹卡逻辑 |
| 全局 app.wxss 不修改品牌色等CSS变量 | 首页局部使用冰蓝配色硬编码，不改动全局暖橙主题变量，避免影响其他页面（地图/我的/收藏等）的配色 |
| TabBar 用纯文字胶囊居中悬浮 | 用户要求悬浮胶囊式纯文字TabBar，选中项蓝色渐变白字 |

## 九、被否定的方案

1. **A方案：Three.js/WebGL真实3D骰子** —— 否定，因为包体大、性能差、用户之前不喜欢3D元素
2. **B方案：GIF/帧动画播放翻滚** —— 否定，需要生成大量帧图且交互不灵活
3. **C方案中使用CSS 3D transform构建真3D立方体（6面图贴在cube上rotate）** —— 部分否定，待机和换位用CSS 2D透视，翻滚用rotateX+rotateY+快速切换骰面模拟（已实现的方案，效果待验证）
4. **骰子指示器跟随骰子颜色变化（红/紫/绿）** —— 用户明确确认「指示点是蓝+灰+灰（蓝色是当前选中），不是跟随骰子颜色」
5. **保留TabBar图标** —— 用户要求纯文字
6. **修改全局CSS变量为冰蓝色** —— 否定，会影响其他页面，首页局部设置背景即可
7. **修复 loadDailyRecommend 缺失问题** —— 用户明确说「不改 不管了」，保留报错不处理
